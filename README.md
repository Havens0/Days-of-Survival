# 🧟 Days of Survival

**A text-based zombie survival adventure made in C++.**

---

### 🎮 How to play
- Run the executable `Days-of-Survival.exe`  
- Type the number of your choice and press ENTER  
- Multiple endings

---

### 🧱 Built with
- C++17
- Standard libraries only (no dependencies)
